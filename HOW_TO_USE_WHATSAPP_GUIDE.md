## 📱 Message Sending Flow

### Day 1: Send Onboarding (Messages 1-6)
These cover the foundation:
- Message 1: Welcome + credentials
- Message 2: What is ETF?
- Message 3: Why treat as ETF?
- Message 4: Monthly topup plans
- Message 5: Risk disclosure 1
- Message 6: Risk disclosure 2

**What to do:**
1. Copy each message from WHATSAPP_ONBOARDING.txt
2. Paste one message at a time in WhatsApp
3. Wait for their response before next message (gives them time to read)
4. After message 6, send: "Ready to setup? 👇"

**Expected time:** 15-30 minutes (investor reads + responds)

---

### Day 2: Send Setup Instructions (Messages 7-11)
These are the action steps:
- Message 7: Download MT5
- Message 8: Login
- Message 9: Verify trades
- Message 10: Open dashboard
- Message 11: Monthly deposits

**What to do:**
1. Check in: "Did you download MT5?"
2. Send messages 7-11 (spaced out, allow time for each step)
3. Have them confirm each step before moving next
4. "Can you see your account balance?" ← Verify they're logged in

**Expected time:** 30-60 minutes (actual setup)

---

### Day 3: Send Reference (Messages 12-17)
These are reminders + support:
- Message 12: Key metrics
- Message 13: DO's and DON'Ts
- Message 14: First week checklist
- Message 15: Support + verification links
- Message 16: Final reminder
- Message 17: Go live

**What to do:**
1. Send messages 12-17 in one batch (they're reminders, not steps)
2. Share WHATSAPP_CHEATSHEET.txt (tell them to pin it)
3. "Save the cheat sheet for quick reference 📌"

**Expected time:** 5 minutes (just sharing)

## 🎯 Key Tips

### DO:
✅ Send one message at a time (not all 17 at once)
✅ Wait for confirmation between steps
✅ Be patient (investor needs time to digest)
✅ Answer questions (keep them confident)
✅ Remind them: "This is normal" if confused

### DON'T:
❌ Dump all messages at once (overwhelming)
❌ Pressure them to deposit immediately
❌ Skip risk disclosure (crucial)
❌ Assume they understand leverage (explain it)
❌ Be vague about drawdown (be specific)
